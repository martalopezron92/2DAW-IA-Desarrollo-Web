# Actividades Conceptuales: Modelos Supervisados

#### Actividad 1: Identificar tipo de problema

**Enunciado**: Para cada caso, indica si es un problema de **clasificación** o **regresión**. Justifica tu respuesta.

a) Predecir el número de visitas que tendrá una web el próximo mes

b) Detectar si un usuario es un bot o una persona real

c) Calcular el tiempo de carga esperado de una página web

d) Clasificar tickets de soporte en categorías: "Urgente", "Normal", "Bajo"

e) Estimar el precio de venta de un dominio web

f) Identificar el idioma de un comentario en un foro

**¿Qué se espera?**: Que identifiques correctamente el tipo de problema y expliques por qué (tipo de salida: categórica o numérica).

**Pistas**:
- Si la respuesta es un número → Probablemente regresión
- Si la respuesta es una categoría/etiqueta → Clasificación
- Pregúntate: ¿Qué tipo de valor debe devolver el modelo?

#### Actividad 2: Detectar errores conceptuales

**Enunciado**: Los siguientes fragmentos contienen errores conceptuales. Identifica el error y explica por qué está mal.

**Fragmento A:**
> "He entrenado mi modelo y tiene un accuracy del 99% en los datos de entrenamiento. Ya está listo para producción."

**Fragmento B:**
> "Mi modelo predice precios de viviendas. He obtenido un accuracy del 85%, así que funciona bien."

**Fragmento C:**
> "El modelo tiene un 80% de accuracy en train y un 82% en test. Claramente hay overfitting."

**Fragmento D:**
> "Para mi sistema de detección de fraude, es igual de grave un falso positivo que un falso negativo."

**¿Qué se espera?**: Que identifiques el error y expliques cuál sería el enfoque correcto.

**Pistas**:
- Piensa en la diferencia entre train y test
- Recuerda qué métricas se usan en clasificación vs regresión
- Considera el impacto de los errores según el contexto

#### Actividad 3: Preguntas razonadas

**Enunciado**: Responde justificando tu razonamiento.

1. ¿Por qué necesitamos dividir los datos en train y test? ¿No sería mejor usar todos los datos para entrenar?

2. Un modelo tiene estos resultados:
   - Accuracy en train: 65%
   - Accuracy en test: 63%
   
   ¿Tiene overfitting, underfitting o está bien? Justifica.

3. En un sistema de recomendación de películas, ¿es grave equivocarse? Compáralo con un sistema de diagnóstico médico.

4. ¿Qué significa que un modelo "generalice bien"? Pon un ejemplo concreto.

5. Tienes un dataset con 100 filas. ¿Cómo las dividirías entre train y test? ¿Por qué?

**¿Qué se espera?**: Respuestas razonadas, no memorísticas. Justifica cada decisión.

**Pistas**:
- Conecta con los conceptos de la teoría
- Piensa en situaciones reales
- No hay respuestas únicas, pero sí razonamientos mejores que otros
