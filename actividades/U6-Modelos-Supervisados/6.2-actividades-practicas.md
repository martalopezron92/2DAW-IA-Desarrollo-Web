#### Actividad 4: Debugging de código

**Enunciado**: El siguiente código tiene errores. Encuéntralos y corrígelos.

```python
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

# Dataset
X = [[1, 2], [3, 4], [5, 6], [7, 8]]
y = [0, 1, 0, 1]

# Dividir datos
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.5)

# Entrenar modelo
modelo = DecisionTreeClassifier()
modelo.train(X_train, y_train)  # ❌ ERROR 1

# Predecir
y_pred = modelo.predict(X_train)  # ❌ ERROR 2

# Evaluar
accuracy = accuracy_score(y_pred, y_test)  # ❌ ERROR 3

print(f"Accuracy: {accuracy}")
```

**¿Qué se espera?**: Que identifiques los 3 errores y los corrijas.

**Pistas**:
- ERROR 1: El método para entrenar no se llama train()
- ERROR 2: ¿Estamos prediciendo sobre el conjunto correcto?
- ERROR 3: ¿El orden de argumentos es correcto?
