### 4. Ejemplo completo: CLASIFICACIÓN

#### 4.1 Contexto del problema

Vamos a predecir si un estudiante **aprobará o no** un curso online basándonos en:
- Horas de estudio semanales
- Cantidad de ejercicios realizados
- Asistencia a tutorías (%)

**Tipo de problema**: Clasificación (Aprobado/Suspenso)

#### 4.2 Código completo con explicaciones

```python
# ============================================
# PASO 1: Importar librerías necesarias
# ============================================
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report

# ============================================
# PASO 2: Crear datos de ejemplo
# ============================================
# En la vida real, cargarías datos desde un CSV o base de datos
# Aquí creamos un pequeño dataset de ejemplo

datos = {
    'horas_estudio': [5, 10, 3, 8, 12, 2, 7, 15, 4, 11, 6, 9, 1, 14, 8],
    'ejercicios_realizados': [10, 25, 5, 20, 30, 3, 18, 35, 8, 28, 12, 22, 2, 32, 19],
    'asistencia_tutorias': [60, 90, 30, 80, 95, 20, 75, 100, 40, 92, 65, 85, 15, 98, 78],
    'aprobado': ['No', 'Sí', 'No', 'Sí', 'Sí', 'No', 'Sí', 'Sí', 'No', 'Sí', 'No', 'Sí', 'No', 'Sí', 'Sí']
}

# Convertir a DataFrame de pandas (como una tabla de Excel)
df = pd.DataFrame(datos)

# Ver las primeras filas para entender los datos
print("📊 Primeras filas del dataset:")
print(df.head())
print("\n")

# ============================================
# PASO 3: Separar Features (X) y Variable Objetivo (y)
# ============================================
# X → Lo que el modelo usa para predecir (features)
# y → Lo que queremos predecir (variable objetivo)

X = df[['horas_estudio', 'ejercicios_realizados', 'asistencia_tutorias']]
y = df['aprobado']

print("🔹 Features (X):")
print(X.head())
print("\n🔹 Variable objetivo (y):")
print(y.head())
print("\n")

# ============================================
# PASO 4: Dividir en conjunto de entrenamiento y prueba
# ============================================
# test_size=0.3 → 30% para test, 70% para train
# random_state=42 → Para que siempre obtengas los mismos resultados (reproducibilidad)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

print(f"📦 Datos de entrenamiento: {len(X_train)} ejemplos")
print(f"📦 Datos de prueba: {len(X_test)} ejemplos")
print("\n")

# ============================================
# PASO 5: Crear y entrenar el modelo
# ============================================
# Usamos un Árbol de Decisión (Decision Tree) - es fácil de interpretar
# max_depth=3 limita la profundidad para evitar overfitting

modelo = DecisionTreeClassifier(max_depth=3, random_state=42)

# 🎓 ENTRENAMIENTO: El modelo aprende de X_train e y_train
modelo.fit(X_train, y_train)
print("✅ Modelo entrenado correctamente\n")

# ============================================
# PASO 6: Hacer predicciones
# ============================================
# Predicciones en datos de ENTRENAMIENTO (para ver si aprendió)
y_train_pred = modelo.predict(X_train)

# Predicciones en datos de PRUEBA (para ver si generaliza)
y_test_pred = modelo.predict(X_test)

print("🔮 Primeras predicciones en test:")
print(f"Valores reales:      {y_test.values[:5]}")
print(f"Valores predichos:   {y_test_pred[:5]}")
print("\n")

# ============================================
# PASO 7: Evaluar rendimiento
# ============================================

# 7.1 ACCURACY (Precisión general)
# ¿Qué % de predicciones son correctas?
train_accuracy = accuracy_score(y_train, y_train_pred)
test_accuracy = accuracy_score(y_test, y_test_pred)

print("📊 EVALUACIÓN DEL MODELO")
print("="*50)
print(f"Accuracy en TRAIN: {train_accuracy*100:.2f}%")
print(f"Accuracy en TEST:  {test_accuracy*100:.2f}%")
print("\n")

# 7.2 MATRIZ DE CONFUSIÓN
# Muestra qué tipos de errores comete el modelo
print("📋 Matriz de Confusión (Test):")
print(confusion_matrix(y_test, y_test_pred))
print("""
Interpretación:
[[TN  FP]   TN = Verdaderos Negativos (Predijo No, era No)
 [FN  TP]]  FP = Falsos Positivos (Predijo Sí, era No)
            FN = Falsos Negativos (Predijo No, era Sí)
            TP = Verdaderos Positivos (Predijo Sí, era Sí)
""")

# 7.3 REPORTE DETALLADO
print("📈 Reporte de clasificación:")
print(classification_report(y_test, y_test_pred))

# ============================================
# PASO 8: Interpretar resultados
# ============================================
print("="*50)
print("💡 INTERPRETACIÓN")
print("="*50)

diferencia = abs(train_accuracy - test_accuracy) * 100

if diferencia > 20:
    print("⚠️  OVERFITTING detectado:")
    print(f"   El modelo funciona mucho mejor en train ({train_accuracy*100:.1f}%)")
    print(f"   que en test ({test_accuracy*100:.1f}%)")
    print("   → El modelo ha memorizado los datos de entrenamiento")
elif train_accuracy < 0.7 and test_accuracy < 0.7:
    print("⚠️  UNDERFITTING detectado:")
    print(f"   El modelo funciona mal tanto en train ({train_accuracy*100:.1f}%)")
    print(f"   como en test ({test_accuracy*100:.1f}%)")
    print("   → El modelo es demasiado simple o faltan features importantes")
else:
    print("✅ El modelo generaliza correctamente")
    print(f"   Train: {train_accuracy*100:.1f}% | Test: {test_accuracy*100:.1f}%")
    print("   → Diferencia aceptable, el modelo ha aprendido patrones generales")

# ============================================
# PASO 9: Hacer una predicción con datos nuevos
# ============================================
print("\n" + "="*50)
print("🔮 PREDICCIÓN CON NUEVO ESTUDIANTE")
print("="*50)

# Nuevo estudiante:
# - Estudia 13 horas/semana
# - Hizo 28 ejercicios
# - Asistió al 88% de tutorías

nuevo_estudiante = [[13, 28, 88]]
prediccion = modelo.predict(nuevo_estudiante)
probabilidad = modelo.predict_proba(nuevo_estudiante)

print(f"Características: {nuevo_estudiante}")
print(f"Predicción: {prediccion[0]}")
print(f"Probabilidades: No={probabilidad[0][0]:.2f}, Sí={probabilidad[0][1]:.2f}")
```

### 5. Ejemplo completo: REGRESIÓN

#### 5.1 Contexto del problema

Vamos a predecir el **precio mensual de un plan de hosting** basándonos en:
- RAM (GB)
- Almacenamiento (GB)
- Ancho de banda mensual (GB)

**Tipo de problema**: Regresión (precio numérico)

#### 5.2 Código completo con explicaciones

```python
# ============================================
# PASO 1: Importar librerías necesarias
# ============================================
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
import matplotlib.pyplot as plt

# ============================================
# PASO 2: Crear datos de ejemplo
# ============================================
datos_hosting = {
    'ram_gb': [2, 4, 8, 16, 2, 4, 8, 32, 4, 8, 16, 2, 16, 32, 8],
    'almacenamiento_gb': [50, 100, 200, 500, 75, 150, 250, 1000, 100, 200, 400, 50, 500, 1000, 300],
    'ancho_banda_gb': [100, 250, 500, 1000, 150, 300, 600, 2000, 250, 500, 1000, 100, 1200, 2500, 700],
    'precio_mensual': [5.99, 12.99, 24.99, 49.99, 7.99, 15.99, 29.99, 89.99, 13.99, 26.99, 45.99, 6.49, 48.99, 92.99, 31.99]
}

df_hosting = pd.DataFrame(datos_hosting)

print("📊 Dataset de planes de hosting:")
print(df_hosting.head(10))
print("\n")

# ============================================
# PASO 3: Separar Features (X) y Variable Objetivo (y)
# ============================================
X = df_hosting[['ram_gb', 'almacenamiento_gb', 'ancho_banda_gb']]
y = df_hosting['precio_mensual']

print("🔹 Features (X): RAM, Almacenamiento, Ancho de banda")
print("🔹 Variable objetivo (y): Precio mensual")
print("\n")

# ============================================
# PASO 4: Dividir en train y test
# ============================================
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)

print(f"📦 Datos de entrenamiento: {len(X_train)} planes")
print(f"📦 Datos de prueba: {len(X_test)} planes")
print("\n")

# ============================================
# PASO 5: Crear y entrenar el modelo
# ============================================
# Usamos Regresión Lineal - busca la mejor línea/plano que ajuste los datos
modelo_regresion = LinearRegression()

# 🎓 ENTRENAMIENTO
modelo_regresion.fit(X_train, y_train)
print("✅ Modelo de regresión lineal entrenado\n")

# ============================================
# PASO 6: Hacer predicciones
# ============================================
y_train_pred = modelo_regresion.predict(X_train)
y_test_pred = modelo_regresion.predict(X_test)

print("🔮 Comparación Real vs Predicho (Test):")
comparacion = pd.DataFrame({
    'Real': y_test.values,
    'Predicho': y_test_pred,
    'Error': y_test.values - y_test_pred
})
print(comparacion)
print("\n")

# ============================================
# PASO 7: Evaluar rendimiento
# ============================================
print("📊 EVALUACIÓN DEL MODELO DE REGRESIÓN")
print("="*60)

# 7.1 MAE - Mean Absolute Error (Error Absoluto Medio)
# ¿Cuánto se equivoca el modelo de media (en euros)?
mae_train = mean_absolute_error(y_train, y_train_pred)
mae_test = mean_absolute_error(y_test, y_test_pred)

print(f"MAE en TRAIN: {mae_train:.2f} €")
print(f"MAE en TEST:  {mae_test:.2f} €")
print("→ Cuanto más bajo, mejor. Indica el error medio en euros.\n")

# 7.2 MSE - Mean Squared Error (Error Cuadrático Medio)
# Penaliza más los errores grandes
mse_train = mean_squared_error(y_train, y_train_pred)
mse_test = mean_squared_error(y_test, y_test_pred)

print(f"MSE en TRAIN: {mse_train:.2f}")
print(f"MSE en TEST:  {mse_test:.2f}")
print("→ Los errores grandes se penalizan cuadráticamente.\n")

# 7.3 RMSE - Root Mean Squared Error (Raíz del MSE)
# Igual que MSE pero en las mismas unidades que la variable objetivo
rmse_train = np.sqrt(mse_train)
rmse_test = np.sqrt(mse_test)

print(f"RMSE en TRAIN: {rmse_train:.2f} €")
print(f"RMSE en TEST:  {rmse_test:.2f} €")
print("→ Similar al MAE pero penaliza más los errores grandes.\n")

# 7.4 R² (Coeficiente de Determinación)
# ¿Qué % de la variabilidad de los precios explica el modelo?
# 1.0 = perfecto, 0.0 = no explica nada
r2_train = r2_score(y_train, y_train_pred)
r2_test = r2_score(y_test, y_test_pred)

print(f"R² en TRAIN: {r2_train:.3f}")
print(f"R² en TEST:  {r2_test:.3f}")
print("→ Valores cercanos a 1.0 indican buen ajuste.\n")

# ============================================
# PASO 8: Interpretar resultados
# ============================================
print("="*60)
print("💡 INTERPRETACIÓN")
print("="*60)

diferencia_mae = abs(mae_train - mae_test)

if r2_test < 0.5:
    print("⚠️  UNDERFITTING detectado:")
    print(f"   R² muy bajo ({r2_test:.2f}) - el modelo no explica bien los datos")
    print("   → Puede que falten features o que la relación no sea lineal")
elif r2_train > 0.95 and r2_test < 0.7:
    print("⚠️  OVERFITTING detectado:")
    print(f"   R² muy alto en train ({r2_train:.2f}) pero bajo en test ({r2_test:.2f})")
    print("   → El modelo se ajusta demasiado a los datos de entrenamiento")
else:
    print("✅ El modelo funciona correctamente:")
    print(f"   - Error medio en test: {mae_test:.2f} €")
    print(f"   - R² en test: {r2_test:.3f}")
    print("   → El modelo generaliza de forma aceptable")

# ============================================
# PASO 9: Visualizar predicciones vs reales
# ============================================
plt.figure(figsize=(10, 6))
plt.scatter(y_test, y_test_pred, alpha=0.7, s=100)
plt.plot([y_test.min(), y_test.max()], [y_test.min(), y_test.max()], 
         'r--', lw=2, label='Predicción perfecta')
plt.xlabel('Precio Real (€)', fontsize=12)
plt.ylabel('Precio Predicho (€)', fontsize=12)
plt.title('Predicciones vs Valores Reales - Test Set', fontsize=14)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# ============================================
# PASO 10: Hacer predicción con nuevo plan
# ============================================
print("\n" + "="*60)
print("🔮 PREDICCIÓN CON NUEVO PLAN DE HOSTING")
print("="*60)

# Nuevo plan: 12 GB RAM, 300 GB almacenamiento, 800 GB ancho banda
nuevo_plan = [[12, 300, 800]]
precio_predicho = modelo_regresion.predict(nuevo_plan)

print(f"📝 Características del nuevo plan:")

print(f"   - Almacenamiento: {nuevo_plan[0][1]} GB")
print(f"   - Ancho de banda: {nuevo_plan[0][2]} GB")
print(f"\n💰 Precio predicho: {precio_predicho[0]:.2f} €/mes")

# Mostrar coeficientes (cuánto influye cada variable)
print(f"\n📊 Coeficientes del modelo:")
print(f"   - RAM: {modelo_regresion.coef_[0]:.2f} € por GB")
print(f"   - Almacenamiento: {modelo_regresion.coef_[1]:.2f} € por GB")
print(f"   - Ancho banda: {modelo_regresion.coef_[2]:.2f} € por GB")
print(f"   - Base (intercept): {modelo_regresion.intercept_:.2f} €")
```

#### 5.3 Interpretación de métricas de regresión

**MAE (Mean Absolute Error)**
- Error promedio en las unidades originales (€)
- Fácil de interpretar: "El modelo se equivoca de media X euros"
- **Ejemplo**: MAE = 2.50€ → En promedio, el modelo predice con ±2.50€ de error

**MSE (Mean Squared Error)**
- Penaliza más los errores grandes
- Más difícil de interpretar (está en unidades²)
- Útil para optimización matemática

**RMSE (Root Mean Squared Error)**
- Raíz cuadrada del MSE → vuelve a unidades originales
- Penaliza errores grandes más que MAE
- **Ejemplo**: RMSE = 3.00€ → Similar al MAE pero da más peso a errores grandes

**R² (Coeficiente de Determinación)**
- Va de 0.0 a 1.0 (puede ser negativo si el modelo es muy malo)
- R² = 1.0 → Predicción perfecta
- R² = 0.8 → El modelo explica el 80% de la variabilidad de los precios
- R² = 0.0 → El modelo no explica nada (tan malo como predecir la media siempre)

### 6. Mini-bloque obligatorio: Comparar Train vs Test

**🎯 Objetivo**: Detectar overfitting o underfitting comparando rendimiento en train y test.

```python
# ============================================
# FUNCIÓN PARA COMPARAR TRAIN VS TEST
# ============================================
def comparar_train_vs_test(modelo, X_train, X_test, y_train, y_test, tipo='clasificacion'):
    """
    Compara el rendimiento del modelo en train vs test
    y detecta posibles problemas de overfitting/underfitting
    """
    
    # Hacer predicciones
    y_train_pred = modelo.predict(X_train)
    y_test_pred = modelo.predict(X_test)
    
    print("="*60)
    print("📊 COMPARACIÓN TRAIN VS TEST")
    print("="*60)
    
    if tipo == 'clasificacion':
        # Para clasificación usamos accuracy
        score_train = accuracy_score(y_train, y_train_pred)
        score_test = accuracy_score(y_test, y_test_pred)
        metrica = "Accuracy"
        
    elif tipo == 'regresion':
        # Para regresión usamos R²
        score_train = r2_score(y_train, y_train_pred)
        score_test = r2_score(y_test, y_test_pred)
        metrica = "R²"
    
    # Mostrar resultados
    print(f"{metrica} en TRAIN: {score_train:.3f}")
    print(f"{metrica} en TEST:  {score_test:.3f}")
    print(f"Diferencia: {abs(score_train - score_test):.3f}\n")
    
    # Interpretar
    diferencia = abs(score_train - score_test)
    
    if score_train > 0.95 and score_test < 0.75:
        print("⚠️  OVERFITTING DETECTADO")
        print("   El modelo funciona MUCHO mejor en train que en test")
        print("   Soluciones:")
        print("   - Simplificar el modelo")
        print("   - Conseguir más datos de entrenamiento")
        print("   - Aplicar regularización")
        
    elif score_train < 0.7 and score_test < 0.7:
        print("⚠️  UNDERFITTING DETECTADO")
        print("   El modelo funciona MAL tanto en train como en test")
        print("   Soluciones:")
        print("   - Usar un modelo más complejo")
        print("   - Añadir más features relevantes")
        print("   - Entrenar durante más tiempo")
        
    elif diferencia < 0.1:
        print("✅ MODELO SALUDABLE")
        print("   El rendimiento es similar en train y test")
        print("   El modelo generaliza correctamente")
        
    else:
        print("⚠️  Diferencia moderada entre train y test")
        print("   Puede haber un ligero overfitting")
        print("   Monitorizar con más datos si es posible")
    
    print("="*60)
    
# ============================================
# EJEMPLO DE USO
# ============================================

# Para el modelo de clasificación del apartado 4:

```

**Regla de oro**: Un modelo que funciona mucho mejor en train que en test NO es útil en producción, porque fallará con datos reales.
