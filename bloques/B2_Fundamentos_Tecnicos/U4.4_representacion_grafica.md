# 📊 Representación Gráfica de Datos

## 🎯 ¿Por qué visualizar datos?

> 💡 "Una imagen vale más que mil palabras"

Los gráficos nos permiten:
- ✅ **Detectar patrones** al instante
- ✅ **Comparar** valores fácilmente
- ✅ **Comunicar** resultados de forma efectiva
- ✅ **Encontrar anomalías** rápidamente

**Ejemplo**: ¿Qué es más claro?

**Tabla**:
```
Mes    Ventas
Ene    5000
Feb    5200
Mar    4800
Abr    6000
May    7500
```

**Gráfico de líneas**: ➡️ Ves la tendencia al instante 📈

## 📊 1. Gráfico de Barras

### ¿Cuándo usarlo?
Para **comparar categorías** o cantidades entre diferentes grupos.

### Ejemplo: Ventas por ciudad

```python
import pandas as pd
import matplotlib.pyplot as plt

# Datos
ventas = pd.DataFrame({
    'ciudad': ['Madrid', 'Barcelona', 'Valencia', 'Sevilla'],
    'ventas': [25000, 18000, 12000, 8000]
})

# Crear gráfico
plt.figure(figsize=(10, 6))
plt.bar(ventas['ciudad'], ventas['ventas'], color='skyblue')

# Personalizar
plt.title('Ventas por Ciudad', fontsize=16, fontweight='bold')
plt.xlabel('Ciudad', fontsize=12)
plt.ylabel('Ventas (€)', fontsize=12)
plt.grid(axis='y', alpha=0.3)

# Añadir valores sobre las barras
for i, v in enumerate(ventas['ventas']):
    plt.text(i, v + 500, f'{v:,}€', ha='center', fontweight='bold')

# Mostrar
plt.tight_layout()
plt.show()
```

### Gráfico horizontal:
```python
plt.barh(ventas['ciudad'], ventas['ventas'], color='coral')
plt.xlabel('Ventas (€)')
plt.title('Ventas por Ciudad')
plt.show()
```

## 📈 2. Gráfico de Líneas

### ¿Cuándo usarlo?
Para mostrar **evolución en el tiempo** o tendencias.

### Ejemplo: Evolución de ventas mensuales

```python
# Datos
meses = ['Ene', 'Feb', 'Mar', 'Abr', 'May', 'Jun']
ventas_2023 = [5000, 5200, 4800, 6000, 7500, 8200]
ventas_2024 = [5500, 5800, 5200, 6500, 8000, 9000]

# Crear gráfico
plt.figure(figsize=(10, 6))
plt.plot(meses, ventas_2023, marker='o', linewidth=2, label='2023', color='blue')
plt.plot(meses, ventas_2024, marker='s', linewidth=2, label='2024', color='green')

# Personalizar
plt.title('Evolución de Ventas Mensuales', fontsize=16, fontweight='bold')
plt.xlabel('Mes', fontsize=12)
plt.ylabel('Ventas (€)', fontsize=12)
plt.legend(fontsize=12)
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### Con datos de Pandas:
```python
df = pd.read_csv('ventas_mensuales.csv')

plt.plot(df['mes'], df['ventas'], marker='o')
plt.title('Ventas Mensuales')
plt.xticks(rotation=45)
plt.show()
```

## 🥧 3. Gráfico de Tarta (Pie Chart)

### ¿Cuándo usarlo?
Para mostrar **proporciones o porcentajes** de un total.

> ⚠️ **Consejo**: Úsalo solo con pocas categorías (máximo 5-6).

### Ejemplo: Distribución de ventas por categoría

```python
# Datos
categorias = ['Electrónica', 'Ropa', 'Comida', 'Hogar']
ventas = [35, 25, 20, 20]

# Crear gráfico
plt.figure(figsize=(8, 8))
plt.pie(ventas, labels=categorias, autopct='%1.1f%%', 
        startangle=90, colors=['#ff9999','#66b3ff','#99ff99','#ffcc99'])

plt.title('Distribución de Ventas por Categoría', fontsize=16, fontweight='bold')
plt.axis('equal')  # Para que sea circular
plt.show()
```

### Con explosión (resaltar una porción):
```python
explode = (0.1, 0, 0, 0)  # Resaltar primer elemento

plt.pie(ventas, labels=categorias, autopct='%1.1f%%', 
        explode=explode, shadow=True, startangle=90)
plt.title('Distribución de Ventas')
plt.show()
```

## 📊 4. Histograma

### ¿Cuándo usarlo?
Para ver la **distribución de valores numéricos** y su frecuencia.

### Ejemplo: Distribución de edades

```python
import numpy as np

# Generar datos de ejemplo (edades aleatorias)
edades = np.random.normal(30, 10, 200)  # Media 30, desv 10, 200 valores

# Crear histograma
plt.figure(figsize=(10, 6))
plt.hist(edades, bins=20, color='lightgreen', edgecolor='black', alpha=0.7)

# Personalizar
plt.title('Distribución de Edades de Usuarios', fontsize=16, fontweight='bold')
plt.xlabel('Edad', fontsize=12)
plt.ylabel('Frecuencia', fontsize=12)
plt.grid(axis='y', alpha=0.3)

plt.tight_layout()
plt.show()
```

### Con datos reales:
```python
df = pd.read_csv('usuarios.csv')

plt.hist(df['edad'], bins=15, color='skyblue', edgecolor='black')
plt.title('Distribución de Edades')
plt.xlabel('Edad')
plt.ylabel('Número de usuarios')
plt.show()
```

## 🔵 5. Gráfico de Dispersión (Scatter)

### ¿Cuándo usarlo?
Para ver la **relación entre dos variables numéricas**.

### Ejemplo: Relación entre precio y cantidad vendida

```python
# Datos
precios = [10, 20, 30, 40, 50, 60, 70, 80]
ventas = [100, 90, 80, 70, 60, 55, 45, 40]

# Crear gráfico
plt.figure(figsize=(10, 6))
plt.scatter(precios, ventas, s=100, c='purple', alpha=0.6, edgecolors='black')

# Personalizar
plt.title('Relación Precio vs Cantidad Vendida', fontsize=16, fontweight='bold')
plt.xlabel('Precio (€)', fontsize=12)
plt.ylabel('Cantidad Vendida', fontsize=12)
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### Con colores por categoría:
```python
df = pd.read_csv('productos.csv')

for categoria in df['categoria'].unique():
    datos = df[df['categoria'] == categoria]
    plt.scatter(datos['precio'], datos['ventas'], label=categoria, s=50)

plt.legend()
plt.title('Precio vs Ventas por Categoría')
plt.xlabel('Precio')
plt.ylabel('Ventas')
plt.show()
```

## 🎨 Gráficos con Seaborn (más bonitos)

### 1. Gráfico de barras con Seaborn:
```python
import seaborn as sns

df = pd.read_csv('ventas.csv')

plt.figure(figsize=(10, 6))
sns.barplot(data=df, x='ciudad', y='ventas', palette='viridis')
plt.title('Ventas por Ciudad')
plt.xticks(rotation=45)
plt.show()
```

### 2. Boxplot (diagrama de cajas):
```python
# Ver distribución de precios por categoría
sns.boxplot(data=df, x='categoria', y='precio', palette='Set2')
plt.title('Distribución de Precios por Categoría')
plt.show()
```

### 3. Heatmap (mapa de calor):
```python
# Correlaciones entre variables
correlaciones = df[['edad', 'precio', 'cantidad']].corr()

sns.heatmap(correlaciones, annot=True, cmap='coolwarm', center=0)
plt.title('Correlaciones entre Variables')
plt.show()
```

## 📊 ¿Qué gráfico usar?

| Objetivo | Tipo de Gráfico | Ejemplo |
|----------|-----------------|---------|
| Comparar categorías | **Barras** | Ventas por ciudad |
| Ver evolución temporal | **Líneas** | Ventas mensuales |
| Mostrar proporciones | **Tarta** | % de ventas por categoría |
| Ver distribución de valores | **Histograma** | Distribución de edades |
| Relación entre 2 variables | **Dispersión** | Precio vs ventas |
| Comparar distribuciones | **Boxplot** | Precios por categoría |

## 🎯 Ejemplo completo: Dashboard de ventas

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Cargar datos
df = pd.read_csv('ventas_completas.csv')

# Crear figura con múltiples gráficos
fig, axes = plt.subplots(2, 2, figsize=(15, 10))
fig.suptitle('Dashboard de Ventas 2024', fontsize=20, fontweight='bold')

# 1. Ventas por ciudad (Barras)
ventas_ciudad = df.groupby('ciudad')['total'].sum().sort_values(ascending=False)
axes[0, 0].bar(ventas_ciudad.index, ventas_ciudad.values, color='skyblue')
axes[0, 0].set_title('Ventas por Ciudad', fontsize=14)
axes[0, 0].set_ylabel('Total (€)')
axes[0, 0].tick_params(axis='x', rotation=45)

# 2. Evolución mensual (Líneas)
ventas_mes = df.groupby('mes')['total'].sum()
axes[0, 1].plot(ventas_mes.index, ventas_mes.values, marker='o', color='green', linewidth=2)
axes[0, 1].set_title('Evolución Mensual', fontsize=14)
axes[0, 1].set_ylabel('Ventas (€)')
axes[0, 1].grid(True, alpha=0.3)

# 3. Distribución de precios (Histograma)
axes[1, 0].hist(df['precio'], bins=20, color='coral', edgecolor='black')
axes[1, 0].set_title('Distribución de Precios', fontsize=14)
axes[1, 0].set_xlabel('Precio (€)')
axes[1, 0].set_ylabel('Frecuencia')

# 4. Top 5 productos (Barras horizontal)
top_productos = df.groupby('producto')['cantidad'].sum().nlargest(5)
axes[1, 1].barh(top_productos.index, top_productos.values, color='purple')
axes[1, 1].set_title('Top 5 Productos Más Vendidos', fontsize=14)
axes[1, 1].set_xlabel('Cantidad Vendida')

plt.tight_layout()
plt.savefig('dashboard_ventas.png', dpi=300, bbox_inches='tight')
plt.show()
```

## 💡 Consejos para buenos gráficos

✅ **Títulos claros**: Siempre incluye un título descriptivo

✅ **Etiquetas en ejes**: Indica qué representa cada eje

✅ **Colores apropiados**: No uses demasiados colores

✅ **Leyendas**: Cuando comparas múltiples series

✅ **Tamaño adecuado**: `figsize=(10, 6)` es un buen punto de partida

✅ **Guarda en alta resolución**: `plt.savefig('grafico.png', dpi=300)`

---

## ✅ Conceptos clave

✔️ **Barras**: comparar categorías

✔️ **Líneas**: evolución temporal

✔️ **Tarta**: proporciones

✔️ **Histograma**: distribución de valores

✔️ **Dispersión**: relación entre variables

✔️ Usa **Seaborn** para gráficos más bonitos

✔️ Personaliza con títulos, etiquetas y colores
