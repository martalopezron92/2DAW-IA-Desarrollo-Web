# 🐼 Fundamentos de Pandas

## 🎯 ¿Qué es Pandas?

**Pandas** es la librería más popular de Python para **manipular y analizar datos**. Su nombre viene de "Panel Data" (datos en panel).

> 💡 **Analogía**: Si Excel es una hoja de cálculo manual, Pandas es Excel con superpoderes y automatizado con código.

**¿Para qué sirve Pandas?**
- ✅ Cargar datos desde CSV, Excel, bases de datos...
- ✅ Limpiar y transformar datos
- ✅ Filtrar, ordenar y agrupar
- ✅ Calcular estadísticas
- ✅ Preparar datos para visualizar

## 📊 Estructura principal: DataFrame

Un **DataFrame** es una tabla de datos con filas y columnas, similar a una hoja de Excel.

```python
     nombre  edad     ciudad
0       Ana    25     Madrid
1     Pedro    30  Barcelona
2     María    22   Valencia
3      Luis    28    Sevilla
```

**Componentes**:
- **Columnas**: Variables (nombre, edad, ciudad)
- **Filas**: Observaciones o registros
- **Índice**: Números a la izquierda (0, 1, 2, 3...)

---

## 🚀 Crear un DataFrame

### Desde un diccionario:
```python
import pandas as pd

# Diccionario con listas
datos = {
    'nombre': ['Ana', 'Pedro', 'María', 'Luis'],
    'edad': [25, 30, 22, 28],
    'ciudad': ['Madrid', 'Barcelona', 'Valencia', 'Sevilla']
}

# Crear DataFrame
df = pd.DataFrame(datos)
print(df)
```

**Salida**:
```
   nombre  edad     ciudad
0     Ana    25     Madrid
1   Pedro    30  Barcelona
2   María    22   Valencia
3    Luis    28    Sevilla
```

---

### Desde una lista de listas:
```python
datos = [
    ['Ana', 25, 'Madrid'],
    ['Pedro', 30, 'Barcelona'],
    ['María', 22, 'Valencia']
]

df = pd.DataFrame(datos, columns=['nombre', 'edad', 'ciudad'])
print(df)
```

## 📁 Cargar datos desde archivos

### 1️⃣ Desde CSV (lo más común)

```python
# Cargar CSV
df = pd.read_csv('datos.csv')

# Ver los datos
print(df)
```

**Opciones útiles**:
```python
# CSV con separador punto y coma
df = pd.read_csv('datos.csv', sep=';')

# CSV con codificación especial
df = pd.read_csv('datos.csv', encoding='utf-8')

# Usar una columna como índice
df = pd.read_csv('datos.csv', index_col='id')

# Leer solo las primeras 100 filas
df = pd.read_csv('datos.csv', nrows=100)
```

---

### 2️⃣ Desde Excel

```python
# Cargar primera hoja
df = pd.read_excel('datos.xlsx')

# Cargar hoja específica
df = pd.read_excel('datos.xlsx', sheet_name='Ventas')

# Cargar desde fila específica (saltar encabezados)
df = pd.read_excel('datos.xlsx', header=2)
```

---

### 3️⃣ Desde JSON

```python
df = pd.read_json('datos.json')
```

---

### 4️⃣ Desde URL

```python
url = 'https://ejemplo.com/datos.csv'
df = pd.read_csv(url)
```

## 🔍 Seleccionar datos

### 1️⃣ **Seleccionar una columna**

```python
# Devuelve una Series (columna individual)
edades = df['edad']
print(edades)

# Alternativa (menos recomendable si el nombre tiene espacios)
edades = df.edad
```

---

### 2️⃣ **Seleccionar varias columnas**

```python
# Devuelve un DataFrame
df_subset = df[['nombre', 'ciudad']]
print(df_subset)
```

**Salida**:
```
   nombre     ciudad
0     Ana     Madrid
1   Pedro  Barcelona
2   María   Valencia
```

---

### 3️⃣ **Seleccionar filas por posición (iloc)**

```python
# Primera fila (índice 0)
primera_fila = df.iloc[0]

# Primeras 3 filas
primeras_tres = df.iloc[0:3]

# Filas 5 a 10
filas_5_a_10 = df.iloc[5:11]

# Última fila
ultima_fila = df.iloc[-1]
```

---

### 4️⃣ **Seleccionar por condición**

```python
# Personas mayores de 25 años
mayores_25 = df[df['edad'] > 25]

# Personas de Madrid
de_madrid = df[df['ciudad'] == 'Madrid']

# Personas entre 20 y 30 años
entre_20_30 = df[(df['edad'] >= 20) & (df['edad'] <= 30)]

# Personas de Madrid O Barcelona
madrid_bcn = df[df['ciudad'].isin(['Madrid', 'Barcelona'])]
```

---

### 5️⃣ **Seleccionar filas y columnas específicas (loc)**

```python
# Fila 0, columna 'nombre'
valor = df.loc[0, 'nombre']

# Filas 0 a 2, columnas 'nombre' y 'edad'
subset = df.loc[0:2, ['nombre', 'edad']]
```

## 📝 Resumen de funciones básicas

| Función | Descripción | Ejemplo |
|---------|-------------|---------|
| `pd.read_csv()` | Cargar CSV | `df = pd.read_csv('datos.csv')` |
| `df.head(n)` | Primeras n filas | `df.head(10)` |
| `df.tail(n)` | Últimas n filas | `df.tail(5)` |
| `df.info()` | Información general | `df.info()` |
| `df.describe()` | Estadísticas | `df.describe()` |
| `df.shape` | Dimensiones | `(100, 5)` |
| `df.columns` | Nombres de columnas | `['nombre', 'edad']` |
| `df['columna']` | Seleccionar columna | `df['edad']` |
| `df[['col1', 'col2']]` | Varias columnas | `df[['nombre', 'edad']]` |
| `df.iloc[n]` | Fila por posición | `df.iloc[0]` |
| `df[condicion]` | Filtrar por condición | `df[df['edad'] > 25]` |

## 🧪 Ejemplo práctico completo

Vamos a trabajar con datos de ventas:

```python
import pandas as pd

# 1. Cargar datos
df = pd.read_csv('ventas.csv')

# 2. Ver primeras filas
print("PRIMERAS 5 FILAS:")
print(df.head())

# 3. Información general
print("\nINFORMACIÓN:")
df.info()

# 4. Estadísticas
print("\nESTADÍSTICAS:")
print(df.describe())

# 5. Ver nombres de columnas
print("\nCOLUMNAS:")
print(df.columns.tolist())

# 6. Seleccionar productos vendidos
productos = df['producto']
print("\nPRODUCTOS:")
print(productos.head())

# 7. Filtrar ventas mayores a 100€
ventas_altas = df[df['precio'] > 100]
print("\nVENTAS > 100€:")
print(ventas_altas)

# 8. Contar cuántas ventas son de Madrid
ventas_madrid = df[df['ciudad'] == 'Madrid']
print(f"\nVentas en Madrid: {len(ventas_madrid)}")
```
