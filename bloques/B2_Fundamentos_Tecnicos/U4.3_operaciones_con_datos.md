# 🔧 Operaciones con Datos en Pandas

## 🎯 Operaciones fundamentales

En este tema aprenderás a **manipular datos** de forma práctica: filtrar, ordenar, agrupar y calcular.

---

## 🔍 Filtrado de datos

### 1️⃣ **Filtros simples**

```python
import pandas as pd

# DataFrame de ejemplo
df = pd.read_csv('ventas.csv')

# Filtrar por edad mayor a 25
mayores_25 = df[df['edad'] > 25]

# Filtrar por ciudad específica
madrid = df[df['ciudad'] == 'Madrid']

# Filtrar por texto que contiene
emails_gmail = df[df['email'].str.contains('gmail')]
```

---

### 2️⃣ **Filtros múltiples (AND)**

```python
# Personas de Madrid Y mayores de 25
madrid_mayores = df[(df['ciudad'] == 'Madrid') & (df['edad'] > 25)]

# Productos caros Y en stock
caros_disponibles = df[(df['precio'] > 100) & (df['stock'] > 0)]
```

> ⚠️ **Importante**: Usa `&` para AND, NO `and`

---

### 3️⃣ **Filtros múltiples (OR)**

```python
# Personas de Madrid O Barcelona
madrid_bcn = df[(df['ciudad'] == 'Madrid') | (df['ciudad'] == 'Barcelona')]

# Productos muy baratos O muy caros
extremos = df[(df['precio'] < 10) | (df['precio'] > 500)]
```

> ⚠️ **Importante**: Usa `|` para OR, NO `or`

---

### 4️⃣ **Filtrar con `.isin()`** (valores en una lista)

```python
# Ciudades específicas
ciudades_grandes = ['Madrid', 'Barcelona', 'Valencia', 'Sevilla']
df_grandes = df[df['ciudad'].isin(ciudades_grandes)]

# Edades específicas
edades_permitidas = [18, 25, 30, 35]
df_edades = df[df['edad'].isin(edades_permitidas)]
```

---

### 5️⃣ **Filtrar por valores nulos**

```python
# Filas con edad nula
sin_edad = df[df['edad'].isnull()]

# Filas con edad NO nula
con_edad = df[df['edad'].notnull()]

# Alternativa
con_edad = df[df['edad'].notna()]
```

---

## 📊 Ordenación de datos

### **Ordenar por una columna**

```python
# Ordenar por edad (ascendente)
df_ordenado = df.sort_values('edad')

# Ordenar por edad (descendente)
df_ordenado = df.sort_values('edad', ascending=False)
```

---

### **Ordenar por varias columnas**

```python
# Primero por ciudad, luego por edad
df_ordenado = df.sort_values(['ciudad', 'edad'])

# Ciudad ascendente, edad descendente
df_ordenado = df.sort_values(
    ['ciudad', 'edad'],
    ascending=[True, False]
)
```

---

### **Resetear índice después de ordenar**

```python
df_ordenado = df.sort_values('edad').reset_index(drop=True)
```

## 🧮 Cálculos y agregaciones

### 1️⃣ **Operaciones básicas**

```python
# Suma de una columna
total_ventas = df['precio'].sum()

# Media
precio_medio = df['precio'].mean()

# Mediana
precio_mediano = df['precio'].median()

# Mínimo y máximo
edad_min = df['edad'].min()
edad_max = df['edad'].max()

# Contar valores
num_ventas = df['precio'].count()

# Desviación estándar
desviacion = df['precio'].std()
```

---

### 2️⃣ **Contar valores únicos**

```python
# Número de ciudades diferentes
num_ciudades = df['ciudad'].nunique()

# Ver cuáles son
ciudades_unicas = df['ciudad'].unique()

# Contar frecuencias
frecuencias = df['ciudad'].value_counts()
```

**Ejemplo de salida**:
```
Madrid        45
Barcelona     32
Valencia      18
Sevilla       12
Name: ciudad, dtype: int64
```

---

### 3️⃣ **Operaciones entre columnas**

```python
# Crear nueva columna calculada
df['total'] = df['precio'] * df['cantidad']

# Calcular descuento
df['precio_con_descuento'] = df['precio'] * 0.9

# Calcular porcentaje
df['porcentaje_vendido'] = (df['vendidos'] / df['stock']) * 100
```

## 👥 Agrupaciones (Group By)

Las agrupaciones nos permiten **resumir datos por categorías**.

### 1️⃣ **Agrupación simple**

```python
# Ventas totales por ciudad
ventas_por_ciudad = df.groupby('ciudad')['precio'].sum()
```

**Salida**:
```
ciudad
Barcelona    15620
Madrid       25430
Sevilla       8900
Valencia     12340
Name: precio, dtype: int64
```

---

### 2️⃣ **Agrupación con múltiples cálculos**

```python
# Estadísticas de precio por ciudad
stats_ciudad = df.groupby('ciudad')['precio'].agg([
    'sum',    # Suma
    'mean',   # Media
    'count',  # Conteo
    'min',    # Mínimo
    'max'     # Máximo
])
```

**Salida**:
```
              sum       mean  count   min    max
ciudad
Barcelona  15620  234.94       66  19.99  899.99
Madrid     25430  189.48      134  12.50  1200.00
```

---

### 3️⃣ **Agrupación por varias columnas**

```python
# Ventas por ciudad y categoría de producto
ventas_detalladas = df.groupby(['ciudad', 'categoria'])['precio'].sum()
```

---

### 4️⃣ **Agrupación con nombres personalizados**

```python
resumen = df.groupby('ciudad').agg(
    ventas_totales=('precio', 'sum'),
    ticket_medio=('precio', 'mean'),
    num_ventas=('precio', 'count')
)
```

**Salida**:
```
           ventas_totales  ticket_medio  num_ventas
ciudad
Barcelona          15620        234.94          66
Madrid             25430        189.48         134
```

## ➕ Añadir y modificar columnas

### **Crear nueva columna**

```python
# Columna con valor fijo
df['pais'] = 'España'

# Columna calculada
df['iva'] = df['precio'] * 0.21

# Columna condicional
df['categoria_edad'] = df['edad'].apply(
    lambda x: 'Joven' if x < 30 else 'Adulto'
)
```

---

### **Modificar columna existente**

```python
# Aplicar descuento a todos los precios
df['precio'] = df['precio'] * 0.9

# Convertir texto a mayúsculas
df['ciudad'] = df['ciudad'].str.upper()
```

---

### **Renombrar columnas**

```python
# Renombrar una o varias columnas
df = df.rename(columns={
    'precio': 'price',
    'ciudad': 'city'
})
```

---

## ❌ Eliminar datos

### **Eliminar columnas**

```python
# Eliminar una columna
df = df.drop('columna_innecesaria', axis=1)

# Eliminar varias columnas
df = df.drop(['col1', 'col2', 'col3'], axis=1)
```

---

### **Eliminar filas**

```python
# Eliminar fila por índice
df = df.drop(0)  # Elimina fila con índice 0

# Eliminar filas con valores nulos
df = df.dropna()

# Eliminar duplicados
df = df.drop_duplicates()
```

## 🔗 Combinar DataFrames

### 1️⃣ **Concatenar (añadir filas)**

```python
# Dos DataFrames con mismas columnas
df1 = pd.DataFrame({'nombre': ['Ana', 'Pedro']})
df2 = pd.DataFrame({'nombre': ['Luis', 'María']})

# Unir verticalmente
df_total = pd.concat([df1, df2], ignore_index=True)
```

---

### 2️⃣ **Merge (unir por columna común)**

```python
# DataFrame de usuarios
usuarios = pd.DataFrame({
    'user_id': [1, 2, 3],
    'nombre': ['Ana', 'Pedro', 'Luis']
})

# DataFrame de compras
compras = pd.DataFrame({
    'user_id': [1, 1, 2],
    'producto': ['Laptop', 'Mouse', 'Teclado'],
    'precio': [899, 25, 45]
})

# Unir por user_id
df_completo = pd.merge(usuarios, compras, on='user_id')
```

**Resultado**:
```
   user_id nombre producto  precio
0        1    Ana   Laptop     899
1        1    Ana    Mouse      25
2        2  Pedro  Teclado      45
```

## 📊 Ejemplo práctico completo

```python
import pandas as pd

# 1. Cargar datos
df = pd.read_csv('ventas_ecommerce.csv')

# 2. Ver información básica
print("PRIMERAS FILAS:")
print(df.head())
print(f"\nTotal de ventas: {len(df)}")

# 3. Filtrar ventas del último mes
ventas_enero = df[df['fecha'].str.contains('2024-01')]
print(f"\nVentas en enero: {len(ventas_enero)}")

# 4. Calcular total vendido
total = df['precio'].sum()
print(f"\nTotal facturado: {total:.2f}€")

# 5. Ventas por ciudad
print("\nVENTAS POR CIUDAD:")
ventas_ciudad = df.groupby('ciudad')['precio'].agg([
    ('total', 'sum'),
    ('media', 'mean'),
    ('cantidad', 'count')
])
print(ventas_ciudad)

# 6. Top 5 productos más vendidos
print("\nTOP 5 PRODUCTOS:")
top_productos = df['producto'].value_counts().head(5)
print(top_productos)

# 7. Crear columna con categoría de precio
def categorizar_precio(precio):
    if precio < 50:
        return 'Económico'
    elif precio < 200:
        return 'Medio'
    else:
        return 'Premium'

df['categoria_precio'] = df['precio'].apply(categorizar_precio)

# 8. Ventas por categoría
print("\nVENTAS POR CATEGORÍA:")
ventas_categoria = df.groupby('categoria_precio')['precio'].sum()
print(ventas_categoria)

# 9. Guardar resultado
df.to_csv('ventas_procesadas.csv', index=False)
print("\n✅ Datos procesados guardados!")
```

## ✅ Conceptos clave

✔️ **Filtrar**: `df[condicion]`, usar `&` y `|`

✔️ **Ordenar**: `sort_values()`

✔️ **Calcular**: `sum()`, `mean()`, `count()`, etc.

✔️ **Agrupar**: `groupby()` con `agg()`

✔️ **Crear columnas**: `df['nueva'] = calculo`

✔️ **Eliminar**: `drop()`, `dropna()`, `drop_duplicates()`
